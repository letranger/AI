* 什麼是語言模型

你每天都在用語言模型，只是你不知道而已。

打開手機輸入「今天天氣」，鍵盤會自動建議「很好」、「不錯」、「真熱」——這背後就是語言模型在運作。Google 搜尋欄打幾個字就會跳出一整串建議，也是語言模型。甚至你在 LINE 上打字時出現的自動完成，統統都是。

#+begin_quote
語言模型的核心任務只有一件事：*根據前面的文字，預測下一個最可能出現的字*。
#+end_quote

** 用數學來說

假設有一句話「我 今天 吃了 一碗 _____」，語言模型的工作就是計算：

- P(拉麵 | 我今天吃了一碗) = 0.15
- P(牛肉麵 | 我今天吃了一碗) = 0.12
- P(飯 | 我今天吃了一碗) = 0.10
- P(水泥 | 我今天吃了一碗) = 0.0001

模型會選擇機率最高的字詞作為預測結果。那這些機率是怎麼來的？答案是：*從大量的文本中統計出來的*。如果模型讀過的文章中，「一碗」後面常常接「飯」、「麵」、「湯」，那這些字的機率就會比較高；「水泥」幾乎從來沒出現在「一碗」後面，所以機率趨近於零。

** 用 Python 感受一下

我們來寫一個最簡單的「語言模型」——統計一段文字中，每個字後面最常接什麼字：

#+begin_src python -r -n :results output :exports both :session lm
text = "我喜歡吃拉麵我喜歡吃牛肉麵我喜歡喝珍珠奶茶我不喜歡吃苦瓜"

# 統計每個字後面接什麼字
next_char = {}
for i in range(len(text) - 1):
    current = text[i]
    follow = text[i + 1]
    if current not in next_char:
        next_char[current] = {}
    if follow not in next_char[current]:
        next_char[current][follow] = 0
    next_char[current][follow] += 1

# 看看「我」後面最常接什麼
print("「我」後面接的字及出現次數：")
for char, count in sorted(next_char["我"].items(), key=lambda x: -x[1]):
    print(f"  {char}: {count} 次")

print()
print("「喜」後面接的字及出現次數：")
for char, count in sorted(next_char["喜"].items(), key=lambda x: -x[1]):
    print(f"  {char}: {count} 次")
#+end_src

預期輸出：
#+begin_example
「我」後面接的字及出現次數：
  喜: 3 次
  不: 1 次

「喜」後面接的字及出現次數：
  歡: 4 次
#+end_example

這個迷你模型雖然只統計了一句話，但已經掌握了語言模型的核心精神：*觀察規律，預測未來*。ChatGPT 做的事情本質上和這個一模一樣，只是它讀了幾乎整個網際網路的資料，模型有數千億個參數，預測的精準度自然不可同日而語。

* 語言模型的進化史

語言模型的發展就像是「猜字遊戲」的進化——從死背到理解，從短視到遠望。

** 第一代：N-gram 模型（數人頭法）

最原始的語言模型就是「數人頭」：統計大量文章中，某幾個字連在一起出現的次數。

例如 Bigram（2-gram）模型只看前一個字：
- 看到「我」→ 預測下一個字（統計「我」後面最常接什麼）
- 看到「今天」→ 預測下一個字（統計「天」後面最常接什麼）

#+begin_src python -r -n :results output :exports both :session lm
import random

# 用 bigram 來「生成」文字
def build_bigram(text):
    """建立 bigram 模型：統計每個字後面各個字出現的次數"""
    model = {}
    for i in range(len(text) - 1):
        c = text[i]
        n = text[i + 1]
        if c not in model:
            model[c] = {}
        model[c][n] = model[c].get(n, 0) + 1
    return model

def predict_next(model, current_char):
    """根據 bigram 模型預測下一個字"""
    if current_char not in model:
        return "？"
    candidates = model[current_char]
    total = sum(candidates.values())
    # 顯示每個候選字的機率
    for char, count in sorted(candidates.items(), key=lambda x: -x[1]):
        prob = count / total * 100
        print(f"  {char}: {prob:.1f}%")
    # 回傳機率最高的
    return max(candidates, key=candidates.get)

corpus = "我喜歡吃拉麵我喜歡吃牛肉麵我喜歡喝珍珠奶茶我不喜歡吃苦瓜我喜歡打籃球"
model = build_bigram(corpus)

print("給定「吃」，模型預測下一個字的機率：")
best = predict_next(model, "吃")
print(f"→ 模型選擇：{best}")
print()
print("給定「歡」，模型預測下一個字的機率：")
best = predict_next(model, "歡")
print(f"→ 模型選擇：{best}")
#+end_src

N-gram 的致命弱點：*記憶力太差*。Bigram 只看前 1 個字，Trigram 看前 2 個字，頂多看到前 4-5 個字就是極限了。面對「小明上週去日本旅遊，他在那裡吃了很多 _____」這種需要理解整句話才能回答的問題，N-gram 完全無能為力——它只看到「多」這個字，根本不知道前面在講日本。

** 第二代：神經網路語言模型

既然 N-gram 記憶力差，那就換一個記憶力好的模型吧！2003 年，Yoshua Bengio 提出了用神經網路來做語言模型的方法。

核心改進：
- *詞向量（Word Embedding）*：把每個字/詞轉換成一串數字（向量），讓意思相近的詞在數學空間中靠得更近。例如「貓」和「狗」的向量會很接近，但「貓」和「微積分」就離很遠
- *學會泛化*：因為相似的詞有相似的向量，模型即使沒看過「我喜歡吃拉麵」，但看過「我喜歡吃牛肉麵」，也能推測出「吃」後面可以接「拉麵」

不過，這個模型的記憶力還是有限——它一次只能看固定長度的前文。

** 第三代：RNN 語言模型

RNN（循環神經網路）的出場解決了記憶力的問題。RNN 有一個「隱藏狀態」會不斷傳遞，理論上可以記住從句子開頭到目前為止的所有資訊。

#+begin_quote
如果 N-gram 是金魚腦（只記得前幾秒），RNN 就是一個認真做筆記的學生——雖然筆記越寫越潦草（記憶會隨距離衰減），但至少有在記。
#+end_quote

後來 LSTM 和 GRU 改良了 RNN 的記憶機制，讓重要的資訊可以保留更久。想了解更多可以參考[[id:263cb433-d0eb-4400-a373-35175c000c01][循環神經網路]]這篇教材。

** 第四代：Transformer 與 GPT（注意力就是你需要的一切）

2017 年，Google 發表了一篇名為《Attention Is All You Need》的論文（光看標題就知道他們有多得意），提出了 *Transformer* 架構，徹底改變了遊戲規則。

Transformer 的核心武器是 *自注意力機制（Self-Attention）*：

#+begin_quote
想像你在讀一篇文章：「小明養了一隻貓，他每天都會餵牠吃飼料。」

當你讀到「牠」的時候，你的大腦會自動回去找「牠」指的是誰——是「貓」，不是「小明」。

Self-Attention 做的就是這件事：讓模型在處理每個字的時候，能夠「回頭看」整句話中所有的字，並判斷哪些字跟當前的字最相關。
#+end_quote

Transformer 相比 RNN 的優勢：

| 比較項目 | RNN | Transformer |
|----------+-----+-------------|
| 處理方式 | 一個字一個字依序處理 | 整句話同時處理 |
| 訓練速度 | 慢（無法平行化） | 快（可以平行化） |
| 長距離記憶 | 容易遺忘 | 透過 Attention 直接連結 |
| 適合規模 | 中小型模型 | 超大型模型 |

OpenAI 用 Transformer 的解碼器（Decoder）打造了 GPT 系列：

| 模型 | 年份 | 參數量 | 里程碑 |
|------+------+--------+--------|
| GPT-1 | 2018 | 1.17 億 | 證明「預訓練 + 微調」路線可行 |
| GPT-2 | 2019 | 15 億 | 太強了，OpenAI 一度不敢公開 |
| GPT-3 | 2020 | 1750 億 | 少樣本學習，不用微調也能用 |
| GPT-4 | 2023 | 未公開 | 多模態，能看圖說故事 |
| GPT-4o | 2024 | 未公開 | 即時語音對話，像電影場景 |

想了解更多 GPT 的應用，可以參考 [[id:22f4856f-104e-4c15-8226-8b9b70bc584b][ChatGPT]] 這篇教材。

** 小結：語言模型進化比較

| 世代 | 模型 | 記憶力 | 比喻 |
|------+------+--------+------|
| 第一代 | N-gram | 只記前幾個字 | 金魚：「前面說了什麼？忘了。」 |
| 第二代 | 神經網路 LM | 固定長度 | 近視眼：看得到附近，看不到遠方 |
| 第三代 | RNN/LSTM | 理論上無限，但會衰減 | 認真但健忘的學生：筆記越寫越潦草 |
| 第四代 | Transformer | 整句話都能看到 | 全知視角：每個字都能直接關聯到任何其他字 |

* 語言模型的應用

語言模型已經滲透到我們生活的各個角落，很多你每天都在用的功能，背後都有語言模型在運作：

1. *手機鍵盤預測*：打字時自動建議下一個詞——最基礎的語言模型應用
2. *語音助手*：Siri、Google Assistant 把你說的話轉成文字（語音辨識），再理解你的意思（語言理解）
3. *機器翻譯*：Google 翻譯、DeepL 能把一種語言翻譯成另一種語言
4. *文字生成*：ChatGPT、Claude 能寫文章、寫程式、回答問題
5. *搜尋引擎*：理解你輸入的搜尋意圖，找出最相關的結果
6. *垃圾信件過濾*：判斷一封信是正常信件還是垃圾信
7. *自動摘要*：把長文章濃縮成重點
8. *程式碼補完*：GitHub Copilot 能根據你寫的註解自動生成程式碼

* 動手做：文字生成器

我們來用 bigram 模型做一個簡單的「文字生成器」，讓電腦自己寫句子：

#+begin_src python -r -n :results output :exports both :session lm
import random

def generate_text(model, start_char, length=20):
    """用 bigram 模型生成文字"""
    result = start_char
    current = start_char
    for _ in range(length):
        if current not in model:
            break
        candidates = model[current]
        # 根據機率隨機選擇下一個字（而不是每次都選最高的）
        chars = list(candidates.keys())
        weights = list(candidates.values())
        current = random.choices(chars, weights=weights, k=1)[0]
        result += current
    return result

# 用比較豐富的語料來訓練
corpus = ("我喜歡吃拉麵我喜歡吃牛肉麵我喜歡喝珍珠奶茶"
          "我不喜歡吃苦瓜我喜歡打籃球我今天吃了一碗拉麵"
          "今天天氣很好我想出去玩今天我要去打籃球"
          "珍珠奶茶很好喝我每天都想喝珍珠奶茶")

model = build_bigram(corpus)

# 生成 5 句話
random.seed(42)
print("=== AI 小作家上線 ===")
for i in range(5):
    sentence = generate_text(model, "我", length=15)
    print(f"第{i+1}句：{sentence}")
#+end_src

你會發現，這個「AI 小作家」寫出來的句子有時候通順，有時候亂七八糟。這是因為 bigram 模型只看前一個字，完全沒有「理解」語意的能力。它純粹是在做機率性的文字接龍。

ChatGPT 之所以能寫出通順的長篇文章，是因為：
1. 訓練資料量大到難以想像（幾乎整個網路）
2. 模型架構（Transformer）能同時看到整段文字的上下文
3. 參數量高達數千億，能記住極其複雜的語言規律
4. 經過人類反饋強化學習（RLHF）的調校

*** 作業一參考解答
重點觀察：
- 語料量越大，生成的句子「看起來」越通順

*** 作業二參考解答
句子 1：「貓」最相關的詞：
- 「牠」→ 指代關係（代名詞指回名詞）
- 「餵」→ 動作的受詞
- 「養」→ 動作的受詞

- 「最高」→ 修飾「建築」的形容詞

| 世代 | 代表模型 | 優點 | 缺點 | 比喻 |
|------+----------+------+------+------|
| 1 | N-gram | 簡單直覺、計算快 | 只能看前幾個字、無法理解語意 | 死背型學生 |
| 2 | FFNN LM | 學會詞向量、能泛化 | 看的範圍仍然固定 | 戴眼鏡的近視學生（看得到但視野有限） |
| 3 | RNN/LSTM | 理論上能記住整句話 | 訓練慢、長距離記憶會衰減 | 一邊跑步一邊背書的人（越跑越喘，後面的都忘了） |
| 4 | Transformer | 能同時看整句話、訓練快 | 需要大量計算資源 | 考試可以帶全部課本的學生（什麼都查得到，就是書包很重） |
